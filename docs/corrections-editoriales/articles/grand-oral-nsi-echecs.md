# grand-oral-nsi-echecs

Format 5+10+5 remplacé par 10+10 après 20 de préparation, choix du jury/support rétablis. Code autonome sur arbre fourni ; faux PGN Deep Blue retiré, PGN fictif cohérent. Hachage≠compression, état complet et bornes de transposition précisés. Shannon≠positions, b=35 non maximum fixe, alpha-bêta asymptotique ; Stockfish NNUE, AlphaZero deux sorties d’un réseau, protocole 2017. Faux lien AlphaZero→AlphaFold et injonctions de récitation supprimés. Anciens SVG reprenant les erreurs retirés du contenu. SEO conservé : la description indique encore bac 2025, explicitement signalé pour relecture.
